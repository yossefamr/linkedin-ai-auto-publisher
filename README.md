# 🚀 LinkedIn AI Auto Publisher

An automated daily publishing bot that uses **Activepieces** and **OpenRouter LLM** to generate and post updates directly to LinkedIn.

## ⚡️ Flow Architecture
1. **Schedule Trigger:** Runs every day automatically.
2. **Code Step:** Formats parameters and context.
3. **OpenRouter LLM:** Generates engaging tech content.
4. **LinkedIn Integration:** Publishes the update directly to the feed.

## 🛠️ Tech Stack
- **Platform:** Activepieces
- **LLM Provider:** OpenRouter
- **Social Integration:** LinkedIn API

## 📝 Setup & Usage
Export the Activepieces JSON flow template and import it into your Activepieces workspace, set your OpenRouter & LinkedIn credentials, and enable the schedule!
